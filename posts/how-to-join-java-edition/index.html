How to join on Java Edition

Published 20th september 2026.

Joining on Java Edition is the normal multiplayer process with one server address.

  1. Open Minecraft Java Edition on any version from 1.7.10 to the latest release.
  2. Go to Multiplayer.
  3. Select Add Server.
  4. Enter any name.
  5. Enter play.nomadanarchy.online as the server address.
  6. Save and double-click the server to join.

The server's native version is 1.12.2.

The world has no rules, no land claims and does not reset.
