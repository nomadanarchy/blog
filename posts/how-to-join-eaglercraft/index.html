How to join on Eaglercraft

Published 20th september 2026.

Eaglercraft is a way to play Minecraft in a browser with no download. You can also read this on the main site's Eaglercraft page, which lists all four client builds directly.

  1. Open the Eaglercraft page on Nomad Anarchy.
  2. Pick a client. The page lists Eaglercraft X 1.8.8 and Eaglercraft X 1.12.2, each in standard and WASM builds. Try a WASM build first. If it won't run, use the standard build.
  3. The client opens with Nomad Anarchy already in its server list.
  4. Click it and press play.

Eaglercraft is unofficial third-party software, not made by Mojang.

Read more on the Eaglercraft page on Nomad Anarchy.
